📜 Core Bot Commands

/today View today's progress bar, targets, earned points, and active streak.
/log [task] [amount] Add completed reps or km to today's count with instant autocomplete.
/set [task] [amount] Directly set or override today's total (or set 0 to reset typos).
/profile View your rank card, tier progress bar, streak, and joined date.
/ranks View full 12-level pack hierarchy and point milestones.
/leaderboard View daily podium and all-time overall standings.
/stats View lifetime volume and total reps completed per discipline.
/history View 7-day point history and completion rates.
/enroll Join the Winter Arc challenge and receive the server role.
